# T&um サンプルLP 要件定義書 v1.1

**対象:** 元町・中華街 白髪染めサロン T&um【ティーアンドアム】  
**用途:** ミセミルWeb 営業提案用サンプルLP  
**作成日:** 2026-09-13  
**位置づけ:** このチャットで確定した店舗調査結果および確認事項を正として作成

## 1. プロジェクト概要

本プロジェクトでは、T&umが現在保有している公式サイト・予約ページ・Instagram等の公開情報を整理し、**「白髪に悩む40〜60代女性が、T&umの考え方・専門性・施術・料金・担当者への安心感を1ページで理解し、そのまま予約へ進めるLP」**の完成イメージを制作する。

T&umにはすでに公式Webサイトが存在し、CONCEPT、MENU、STAFF、Hair Style、ブログ、MAP、予約等の情報も揃っているため、今回の提案価値は「Webサイトを持つこと」そのものではない。**既存の良い情報を、初めて訪れる顧客にとって理解しやすい順序へ再編集し、予約までの導線を一つのページに整理すること**を主眼とする。

## 2. サンプルLPの目的

### 最優先目的

**新規顧客のWeb予約への心理的・情報的ハードルを下げる。**

単に予約ボタンを目立たせるのではなく、**共感 → 理解 → 技術への期待 → 人への信頼 → 料金への安心 → 予約**という順番で意思決定を補助する。

### 営業提案上の目的

T&um側に対して、**「現在すでにお持ちの魅力や情報を、1ページに整理するとこのように見せられる」**という具体的な完成イメージを提示する。既存サイトを否定・批判する提案にはしない。

## 3. LPの成功条件

1. FVを見ただけで「白髪に悩む大人女性向けのサロン」であることが分かる。
2. スクロールすることで「白髪を隠すだけではない」というT&umの考え方が理解できる。
3. 白髪ぼかし・脱白髪染めなど、主要サービスの違いが大まかに理解できる。
4. 永野氏がどのような美容師なのか分かり、施術者への安心感を形成できる。
5. 主な料金が予約前に分かる。
6. 店舗所在地・営業時間・アクセスが容易に確認できる。
7. PC・スマートフォンとも「Web予約」が迷わず見つかる。
8. 既存公式サイトの単なる模倣ではなく、新しい情報設計・世界観として成立する。

## 4. ターゲットユーザー

### Primary Target

**40〜60代女性。特に50代を中心とする、白髪や年齢による髪の変化に悩んでいる女性。**

### 想定する悩み

- 白髪染めを繰り返すことによるダメージが気になる
- 染めても根元がすぐ気になる
- 白髪染めによって髪色が暗くなりがち
- 年齢とともに髪質や見た目の変化を感じる
- 白髪をどう扱えばよいか分からない
- 自分に白髪ぼかしが合うのか分からない
- 初めての美容室なので技術・価格・施術者に不安がある

## 5. 顧客に与えたい最終印象

LP閲覧後、ユーザーが**「白髪をただ染めるだけではなく、自分に合う方法を一緒に考えてくれそう。」**、さらに**「料金や担当する人も分かったので、一度相談・予約してみよう。」**と感じる状態を目指す。

「若返り」「老けない」など年齢不安を過度に煽る方向ではなく、**年齢を重ねた髪を自然に美しく見せる**というポジティブな方向を優先する。

## 6. ブランド・訴求の中核

### ① 白髪を「隠す」だけではなく「活かす」
T&umのブランド思想の中心。

### ② 大人女性の白髪ケアへの専門性
「美容室で白髪染めもできます」ではなく、**白髪そのものを中心課題として扱うサロン**として位置づける。

### ③ 一人ひとりへのカウンセリング
白髪ぼかし、通常カラー、ヘナ、ヘアマニキュアなど複数の選択肢を持ち、髪や希望に合わせて提案する姿勢を見せる。

### ④ 永野良一氏への信頼
サロンという箱だけではなく、**「誰に任せるのか」**まで見えるLPとする。

## 7. コンバージョン設計

### Primary CTA

**「Web予約する」**

既存のRe:pit予約ページへ外部遷移する。配置はHeader、Hero、Price付近、Access付近、Final CTA、モバイル固定CTAを基本とする。ただし各セクションにCTAを乱立させず、広告的な圧を避ける。

### Secondary CTA

候補は**「LINEで相談する」**。ただし一般顧客向け相談窓口として利用できることを確認できた場合のみ採用する。未確認のまま「LINE相談できます」と断定しない。確認できない場合はInstagramまたは電話をSecondary CTAとする。

### 9.3 Problem
ターゲットが「自分のことだ」と感じる導入。根元の白髪、暗い白髪染め、ダメージ、年齢による髪質変化等を、必要以上に不安を煽らない表現で整理する。

### 9.4 Concept / About T&um
主メッセージは**「白髪を無理に隠すのではなく、その人らしい美しさへ変えていく。」**。大人女性の白髪悩みに特化、一人ひとりへのカウンセリング、髪・頭皮への負担にも配慮した選択肢、落ち着いて相談できる環境を伝える。

### 9.5 Features
3項目程度に絞る。
1. 白髪ケアに向き合う専門性
2. 一人ひとりに合わせるカウンセリング
3. 落ち着いて相談できるプライベート空間

「完全マンツーマン」「必ず永野氏が担当」等、未確認情報は記載しない。

## 11. 素材要件

### A. 実店舗素材
Instagram使用許可済み素材のみ、実店舗・実施術・実際のお客様素材として扱う。

### B. AI生成素材
今回はInstagram実写真が少ないため、Hero、Problem、Concept、Gray Hair Design、Style、First Visit、FAQ、Access、Reservationのビジュアルに使用してよい。

ただしAI画像を、実際のお客様、実際の施術実績、Before / After、実際のT&um店内、永野氏本人、実際の店舗外観・アクセス経路として断定しない。

Style等でAI画像を使う場合は、近接箇所に「※一部イメージ画像を使用しています」等の注記を設ける。

### C. 使用禁止素材
- Googleマップ掲載写真
- 使用許可を確認していない第三者投稿
- 公式Webサイト上にあるだけで利用許可を得ていない写真
- 他美容室の写真
- AI画像を実際の施術実績・実店舗・本人写真として表示

## 13. キャンペーン・期間限定情報

常設情報を優先する。期間限定情報はサンプルの陳腐化、誤情報化、更新工数につながるため原則中心に置かない。

## 14. レスポンシブ要件

**Mobile Firstに近い優先順位**で設計する。

確認必須幅：375 / 390 / 430 / 768 / 1024 / 1440px。

モバイルでは以下を重視する。
- 本文を極端に小さくしない
- CTAのタップ領域を十分確保
- 長い横スクロールを作らない
- カルーセル操作を必須にしない
- 小さなアイコンだけで意味を伝えない
- 薄すぎる文字色を使用しない

## 15. アクセシビリティ要件

- HTML見出し階層を正しく使用
- ボタンとリンクの役割を明確化
- 意味のある画像にalt
- 装飾画像は不要な読み上げをさせない
- Keyboard操作可能
- Focus状態を消さない
- テキストと背景のコントラストを確保
- CTAを色だけで区別しない

## 16. 技術要件

- Next.js
- React
- TypeScript
- CSSまたは必要最小限のスタイリング構成
- Static Export
- GitHub repository管理

JavaScript用途はハンバーガーメニュー、Scroll Reveal、Anchor navigation程度に留め、過剰なアニメーションライブラリは導入しない。

## 17. サンプル公開要件

営業提案用であり正式サイトではないためGitHub Pagesでのサンプル公開を許容する。

必須：`noindex`、`nofollow`。

営業サンプルではLocalBusiness構造化データを原則入れない。正式店舗サイトではないページから検索エンジンへ店舗実体情報を発信する必要がないため。

## 18. SEO要件

今回は検索流入獲得用本番サイトではないが、正式化を見越してHTML構造は適切にする。

- 一意なtitle
- meta description
- H1は原則1つ
- H2/H3階層
- semantic HTML
- alt
- 適切な内部anchor

サンプルtitle案：**元町・中華街の白髪ケアサロン T&um｜白髪ぼかし・脱白髪染め**

## 19. パフォーマンス要件

- 画像をWeb向けに最適化
- 不要な巨大画像を使用しない
- CLSにつながる画像サイズ未指定を避ける
- 不要な動画背景を避ける
- 初期表示に巨大JavaScriptを要求しない

## 20. アニメーション要件

**動きは上品かつ控えめ**とする。Fade、slight translate、image reveal、header transition程度を許容。過度なパララックス、激しいズーム、大量の文字アニメーション、操作を待たせる演出は禁止方向。`prefers-reduced-motion`に配慮する。

## 25. デザイン工程へ渡す最重要条件

- **ターゲット:** 40〜60代、とくに50代女性
- **ブランド思想:** 白髪を無理に隠すのではなく、自然に活かす
- **ユーザー体験:** 共感 → 期待 → 信頼 → 安心 → 予約
- **表現:** 若者向けトレンド美容室にしない
- **写真:** 実写真は事実証拠、AIは世界観・ヘアデザイン・雰囲気の補助。AIを実績・実店舗・本人と誤認させない

## 26. 結論

今回のLPは、**「元町の白髪染め美容室を紹介するページ」ではなく、「白髪に悩む大人女性が、自分にも選択肢があると気づき、T&umの考え方・技術・人・料金に安心して予約できるページ」**として設計する。

特に、**Problem → Concept → Gray Hair Design → Style → Owner → Price**の中盤まででT&umの価値を十分理解させ、その後にFirst Visit・Access・Reservationで行動障壁を取り除く構造を核とする。
